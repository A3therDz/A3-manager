# UI 设计方案(3 选 1)

> 对应 `目标.md` 的 **D1:磨砂玻璃 / 亚克力 + 立体感 + 完整动画**。
> 三张效果图都是**同一套布局**(顶栏 / 左侧栏 / 网格 / 详情),只换材质与光影,
> 方便直接比较。图在 `design/mockups/` 下,点开可放大。

---

## 共同点(三个方案都做)

| 项 | 做法 |
|---|---|
| 顶栏 | 无白边,自绘顶栏 + 系统最小化/最大化/关闭按钮(`titleBarOverlay`),顶栏即拖拽区 |
| 层级 | 背景层(渐变/光晕) → 内容面板(半透明) → 卡片(更高一层) → 悬浮/弹层(最高) |
| 动效 | 面板进出 180–260ms 缓动、网格卡片错峰渐入(每张 20ms 延迟)、详情切换淡入+位移、滑块与开关过渡、hover/按下双向反馈、模态遮罩渐显 |
| 性能 | 只用 `transform` / `opacity` / `filter` 做动画;卡片不因 hover 改变布局尺寸;8061 张滚动不卡 |
| 主题 | 暗/亮两套都成立,由设置里的滑块切换(已有),两主题共用同一套层级语言 |

---

## 方案 A —— 亚克力工作台(Acrylic Workbench)

![A](mockups/A-acrylic.png)

- **材质**:深色亚克力。面板 `rgba(18,23,31,.66)` + `backdrop-blur(20px)`,
  1px 高光内边(inset 0 1px 0 rgba(255,255,255,.06))、外投影 18–22px。
- **立体感**:靠**层叠**而不是描边——面板浮在背景光晕上,卡片再浮在面板上。
- **动效风格**:克制、短促(160–200ms),像原生 Windows 11 应用。
- **优点**:最稳、最像桌面软件,长时间看图不累眼;性能最好(模糊面积可控)。
- **缺点**:深色 + 玻璃,层次全靠投影,显示器对比度低时容易"糊成一片"。
- **适合**:想要"专业工具"质感。

## 方案 B —— 景深画廊(Depth Gallery)

![B](mockups/B-depth.png)

- **材质**:深色 + 彩色光晕背景(蓝紫/粉),面板半透明但**更薄**,重点在图片本身的浮起。
- **立体感**:强景深——hover 的卡片放大 1.02 并前移(-6px),投影从 26px 拉到 34px;
  详情面板像"悬在画面上方"(投影 40–80px),背景有模糊光团。
- **动效风格**:更明显、更"有戏"(220–280ms),卡片进场错峰,选中项呼吸式高亮。
- **优点**:最符合"景深"和"不简陋"的要求,图片是主角,视觉冲击强。
- **缺点**:彩色光晕较重,长时间使用比 A 累;性能开销略高(光晕 + 大投影)。
- **适合**:想要"作品集/画廊"质感。

## 方案 C —— 亮色玻璃(Luminous Glass)

![C](mockups/C-light-glass.png)

- **材质**:浅色玻璃拟态。白 62–82% 半透明 + `blur(18–22px) saturate(1.4)`,
  细边框 `rgba(15,23,42,.08)`,顶部 1px 白高光。
- **立体感**:靠**柔和投影 + 白色高光边**,类似 macOS / Fluent 亮色模式。
- **动效风格**:轻盈(180–220ms),弹层用轻微缩放 + 淡入。
- **优点**:白天/亮环境下最舒服,缩略图颜色最准(不被深色底压暗)。
- **缺点**:与"深色看图"习惯相反;纯白背景上彩色缩略图会有轻微"浮起"感。
- **适合**:主要在白天使用、或显示器亮度低。

---

## 推荐

**推荐 A 作为默认,吸收 B 的两个点**:卡片 hover 的浮起 + 详情面板的大投影;
光晕强度取 A/B 之间。这样既保持桌面工具的可读性和性能,又有明显的景深。

理由:这个工具的主场景是**长时间翻图 + 看参数**,需要的是层次清晰而不是炫;
B 的光晕在几千张图滚动时会增加 GPU 负担,C 的亮色与纯看图场景不太搭。

## 选定方案后要改的东西(工作量参考)

| 文件 | 改动 |
|---|---|
| `src/main/index.ts` | 窗口参数:`titleBarStyle` / `titleBarOverlay` / `frame`,跟随主题换顶栏颜色 |
| `src/renderer/main.tsx` | 全局 CSS:材质变量(模糊半径/透明度/投影档位)、动效时长与缓动曲线、两套主题色阶 |
| `src/renderer/App.tsx` | 顶栏改成拖拽区 + 窗口按钮留白;工具条、设置弹层、右键菜单、Toast 的材质与进出动画 |
| `src/renderer/components/*.tsx` | 卡片浮起/选中态、详情面板进出、树节点展开动画 |
| `docs` | 把最终配色写成一份 `design/THEME.md`,方便以后加新界面时对齐 |
